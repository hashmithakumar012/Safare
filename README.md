# Safare

Safare (Safe + Care) is a women's safety application developed as a hackathon project. The platform helps women stay safe through emergency assistance, location sharing, SOS alerts, and quick access to support resources.

## Features
- SOS Emergency Alert
- Real-Time Location Sharing
- Emergency Contact Notifications
- Safety Resources
- User-Friendly Interface

## Tech Stack
- HTML
- CSS
- JavaScript
- Java
- Visual Studio Code

## Purpose
The goal of Safare is to improve women's safety by providing quick access to emergency support and communication tools.

## Team
Developed as a Hackathon Project.
