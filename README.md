# Safare

Safare (Safe + Care) is a women's safety application developed for a hackathon. The platform helps women stay safe by providing emergency assistance, real-time location sharing, SOS alerts, and quick access to support resources.

## Features
- SOS Emergency Alert
- Real-Time Location Sharing
- Emergency Contact Notifications
- Safety Resources
- User-Friendly Interface
